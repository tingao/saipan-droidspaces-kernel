# NOT in the list above, because this ROM refuses to disable them:
#
#   com.motorola.android.fota    Motorola's FOTA updater
#   com.motorola.ccc.ota         Motorola CCC over-the-air updater
#   com.motorola.paks
#   com.motorola.fmplayer
#   com.motorola.android.fmradio
#
# `pm disable-user --user 0` fails with "Failure: package is non-disable",
# `pm uninstall --user 0` fails the same way, `com.motorola.paks` reports
# "package is protected", and `pm hide` reports "new hidden state: false" and
# does not stick. Motorola has marked them non-disableable in the framework, so
# they cannot be removed from here.
#
# What debloat-apply.sh does instead: strips their background execution via
# appops and force-stops them. That is the part that actually costs anything on a
# headless device, and it is reversible.
#
# The OTA updaters are the ones that matter. An over-the-air update on an
# unlocked bootloader with a custom kernel is how this device gets bricked, so
# they are worth the extra handling even though the package itself stays.
# ---------------------------------------------------------------------------
